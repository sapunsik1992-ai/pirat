ПЛАН СОЗДАНИЯ ПРОЕКТА: ЦИФРОВОЙ МАГАЗИН AI ПОДПИСОК

1. ЦЕЛЬ ПРОЕКТА
- Создать простой сайт-приложение для продажи подписок на AI-сервисы и готовых аккаунтов.
- Упростить покупку для клиента: каталог, корзина, оплата, выдача доступа.
- Упростить работу владельцу: уведомления, админка заказов, ручная выдача доступа.

2. КЛЮЧЕВЫЕ ФУНКЦИИ MVP
- Главная страница с каталогом товаров.
- Страница товара с описанием, ценой, преимуществами и CTA.
- Корзина покупателя.
- Оформление заказа с контактами.
- Онлайн-оплата через платежную систему.
- Страница подтверждения оплаты.
- Telegram-уведомления владельцу о новом заказе.
- Админ-панель для просмотра заказов.
- Статусы заказов: новый, оплачен, выдан, завершен.
- Выдача доступа вручную покупателю.
- Поддержка через Telegram или чат-виджет.

3. СТЕК ТЕХНОЛОГИЙ
- Next.js
- TypeScript
- Tailwind CSS
- Supabase (база данных)
- YooKassa / CloudPayments / Robokassa
- Telegram Bot API
- Vercel для деплоя

4. БАЗОВАЯ СТРУКТУРА САЙТА
- Главная страница
- Каталог товаров
- Карточка товара
- Корзина
- Оформление заказа
- Страница оплаты
- Страница успешной покупки
- Админка
- Список заказов
- Детали заказа
- Страница поддержки

5. БАЗА ДАННЫХ
Таблицы:
- products: товары, цены, описание, категория, активность
- categories: категории товаров
- orders: заказы, сумма, статус, пользователь, дата
- payments: информация о платеже, статус, ID платежа
- delivery_data: логины, пароли, ссылки, данные доступа
- users: клиенты и контакты
- admin_users: администратор

6. ПРОЦЕСС РАЗРАБОТКИ
Этап 1. Подготовка и планирование
- определить список товаров
- определить структуру страниц
- подготовить описание условий, правил и возвратов

Этап 2. Создание каркаса проекта
- инициализация приложения
- настройка маршрутов
- базовый дизайн
- создание компонентов

Этап 3. Разработка каталога и корзины
- карточки товаров
- корзина
- расчет суммы
- удаление и изменение количества

Этап 4. Оформление заказа
- форма контактов
- создание заказа
- сохранение в базе
- переход к оплате

Этап 5. Платежи и webhook
- подключение платежной системы
- обработка webhook
- изменение статуса заказа
- уведомление владельцу

Этап 6. Админ-панель
- список заказов
- статус заказа
- данные доступа
- ручная выдача товара

Этап 7. Поддержка и уведомления
- Telegram бот
- кнопка связи с владельцем
- базовый чат или ссылка в Telegram

Этап 8. Тестирование и запуск
- проверка корзины
- проверка оплаты
- проверка уведомлений
- проверка выдачи данных
- подготовка к деплою

7. ВАЖНЫЕ РИСКИ И УЧЕТ
- перепродажа аккаунтов может быть юридически и технически рискованной
- важно учитывать правила сервисов и защититься документально
- нужно хранить логи и данные по заказам
- нужно учитывать комиссии платежных систем
- обязательна защита админки и доступа к данным

8. ПРИОРИТЕТЫ НА ПЕРВОМ ЭТАПЕ
1. Главная страница и каталог
2. Корзина и оформление заказа
3. Оплата
4. Уведомления в Telegram
5. Админка заказов
6. Поддержка
7. Улучшение дизайна и UX

9. ВЫВОД
- Сначала запускаем простой, рабочий MVP.
- Не тратим время на сложные функции без проверки спроса.
- Главный фокус — продать и удобно управлять заказами.

10. РЕКОМЕНДУЕМОЕ НАЧАЛО
- Сначала один тип товара: подписка на AI-сервис.
- Далее добавить готовые аккаунты как отдельную категорию.
- Потом расширять каталог и обработку.
